# Jesse Bodde — AI Trainee motivatie-website

Interactieve website die dient als motivatiebrief voor het AI Traineeship bij
[The Automation Group](https://theautomationgroup.nl/nl/werken-bij/ai-trainees).
In plaats van een traditionele brief laat deze site zien hoe Jesse denkt, bouwt en leert:
een werkend voorbeeld van AI-automatisering en agentic workflows.

## Secties

- **Hero** — introductie en directe CTA
- **Over mij** — persoonlijk verhaal, waarom AI, manier van leren, vrije tijd
- **Vaardigheden** — filterbare skillset met live percentages
- **Projecten** — Leadz Systems en andere AI-automatiseringsprojecten
- **Waarom dit traineeship** — motivatie specifiek gericht op The Automation Group
- **Tijdlijn** — interactieve roadmap van opleiding tot AI-praktijk
- **AI Playground** — stel een vraag, krijg een persoonlijk antwoord
- **Contact** — LinkedIn, e-mail, CV-download

## Tech stack

React · Next.js (App Router) · TypeScript · Tailwind CSS · Framer Motion · Lucide Icons

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) om de site lokaal te bekijken.

```bash
npm run build
```

bouwt de productieversie.
